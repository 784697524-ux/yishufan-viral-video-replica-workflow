# 双模型 ASR 证据摘要

本页从原始拉片证据中摘录实际运行结果，展示为什么 Skill 同时使用 Paraformer v2 和 v1，并把差异交给人工复核。

| 时间码 | Paraformer v2 | Paraformer v1 | 处理 |
|---|---|---|---|
| 0.18–4.12 | 愁云淡淡雨潇萧，暮暮复朝朝。 | 愁云淡淡雨潇潇，暮暮复朝朝。 | “潇萧/潇潇”不一致，需复核 |
| 4.80–9.55 | 别来应是眉峰翠，剪婉玉香萧小轩。 | 别来应是眉峰翠减，婉玉香销。 | 断句及字词不一致，需复核 |
| 9.04–12.57 | 独坐相思处，情绪好无聊。 | 小轩独坐相思处，情绪好无聊。 | 起句不一致，需复核 |
| 13.34–17.35 | 一丛萱草，几杆修竹，树叶芭蕉。 | 一丛萱草，几竿修竹，数叶芭蕉。 | 量词不一致，需复核 |

本参考片是画外古诗朗读，不是角色口型对白。实际分析结合可见字幕、画面和语境后，保留其“诗词旁白”功能；未经复核的机器转写不会自动进入新片脚本。
