# 三种复刻模式与反转节拍规范

## 零、全局视觉世界硬约束

三种模式只决定复刻哪些结构，不覆盖用户明确指定的媒介、人物/IP方向和画面世界。开始脚本前必须单独写出“视觉世界硬约束”。例如用户要求历史艺术化人物、油画/CG质感或古今错位时，即使选择“爆款机制迁移”，也不得擅自改成现代真人言情。

用户没有明确指定视觉世界时，才能按各模式的“可以替换”范围处理。不得把“可以替换场景和人物”解释为可以丢弃参考片最主要的视觉辨识方向。

## 一、模式合同

| 模式 | 核心目标 | 必须保留 | 可以替换 | 不得强行加入 |
|---|---|---|---|---|
| 高保真视觉复刻 | 新题材看起来仍沿着原片的镜头语言运行 | 镜头顺序、时长比例、景别、机位、运镜、动作方向、视线关系、转场载体、场景结构、光线和色彩 | 人物身份、剧情道具、商品 | 原片没有的黄金三秒冲突、额外反转、不同运镜 |
| 爆款机制迁移 | 在新题材中复现原片的停留和传播机制 | 停留点、误判路径、权力变化、反转层级、情绪升级、结尾记忆点、商品功能、用户指定的视觉世界 | 镜头顺序、未被用户锁定的场景/人物/道具、视觉构图 | 只换皮的逐镜照抄、无因果怪事堆叠、把指定艺术世界改成无关真人题材 |
| 商业混合复刻 | 兼顾前三秒转化钩子和原片视觉辨识度 | 0至3秒冲突钩子；3秒后原片镜头顺序、时长比例、视觉节拍和光色关系；商品因果解题 | 前三秒的镜头安排、人物、道具、商品 | 3秒以后继续完全脱离原片、自顾自套冲突模板 |

每次输出必须列出“必须保留”和“允许替换”的具体项目。没有写进合同的内容不得事后声称已经复刻。

## 二、模式路由

按以下优先级判断：

1. 用户明确指定模式：直接执行。
2. 用户要求镜头、时长、运镜或动作尽量一样：高保真视觉复刻。
3. 用户要求换题材但保留爆点、爽点、反转或传播逻辑：爆款机制迁移。
4. 用户要求带货、团购或卡券，同时强调前三秒钩子和后续像原片：商业混合复刻。
5. 多个条件冲突且会改变脚本时：询问一次，不得默认全部叠加。

## 三、高密度反转不是“每秒乱转”

先用逐帧证据找出反转簇，再选择节拍密度：

- 跟随原片：按实测有效信息变化间隔执行。
- 标准密度：通常每2至3秒出现一次有效信息变化。
- 高密度反转：仅在指定反转簇内，每1秒至少出现一次有效信息变化；全片仍可有铺垫和喘息。

有效信息变化只包括以下八类：

1. 权力变化：上位者变被动、弱者取得主动。
2. 目标变化：人物刚要做的事被改写。
3. 因果变化：刚才动作的真实后果被揭晓。
4. 风险变化：个人小事升级为群体、空间或更大损失。
5. 道具含义变化：普通物件被重新解释为关键工具、证据或危险物。
6. 观众认知变化：原以为是真相，下一秒被证明只是表象。
7. 空间或身份变化：场景被揭晓为片场、屏幕、梦境或另一层观看空间。
8. 得失变化：人物刚占到便宜又立即付出更大代价。

以下不计为反转：同一动作换角度、人物继续喊叫、无新后果的爆炸重复、仅增加特效、与前因无关的新怪事。

## 四、逐秒反转链写法

高密度反转档先写表，再写对白：

| 秒点 | 画面事实 | 观众此刻判断 | 新变化类型 | 权力持有者 | 下一秒因果 |
|---|---|---|---|---|---|
| 0-1 |  |  |  |  |  |
| 1-2 |  |  |  |  |  |
| 2-3 |  |  |  |  |  |

合格的反转链通常沿着以下路线升级：

```text
身份与空间错位
→ 普通冲突被放大
→ 弱者突然反击
→ 道具含义被改写
→ 原场景被揭示为另一层空间
→ 刚解释清楚又造成真实后果
→ 第三方观看或循环结尾再次改写现实层级
```

这只是结构语法，不是固定剧情。新片必须更换具体事件，并保证每一步由前一步造成。

## 五、递进要求

高密度不等于同一强度连续堆叠。每2至3秒至少跨越一个层级：

```text
语言误会 < 动作反击 < 身份或权力翻转 < 空间真相翻转 < 真实后果翻转
```

若连续两秒只是同一动作延续，必须压缩；若每秒都出现无关设定，必须删减并补足因果。可复用的不是某一种历史人物，而是“熟悉的日常动作 + 高度不相容的身份或空间”形成的反差，再用普通道具重新解释极端事件。

## 六、三种模式的分镜验收

### 高保真视觉复刻

- 每个新镜头都有唯一对标镜头。
- 镜头顺序不乱，时长比例偏差有明确说明。
- 机位、运镜、动作方向和转场载体均可从静态分镜与动作三态中验证。
- 光线与色彩记录为主光方向、色温、明暗反差、背景饱和度和关键高光，不只写“电影感”。

### 爆款机制迁移

- 每个新镜头都对应原片的心理功能或有效信息变化。
- 高密度区间内逐秒有新增变量，且每2至3秒升级一次。
- 反转改变观众判断或人物处境，不是只换构图。
- 商品若出现，必须解决剧情中的真实问题。

### 商业混合复刻

- 0至3秒具有独立冲突钩子。
- 3秒后的镜头顺序、时长比例和视觉节拍重新与原片对齐。
- 商品进入时间和功能写入因果链，不以口播打断剧情。
- 结尾同时保留原片记忆点功能和明确商业行动方向。
