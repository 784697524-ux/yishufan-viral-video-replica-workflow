# 艺术范爆款短视频复刻调用模板（v5）

静态插画改填“对标来源：静态插画集<目录>”。先逐图分析，不写不存在的视频时间/ASR。静态商业混合继承画法与色彩，全片叙事原创。

将以下内容粘贴到新任务，并替换尖括号中的内容：

```text
[$yishufan-viral-video-replica-workflow]

对标视频：<本地完整路径或公开链接>
商品资料：<商品截图、详情截图或素材目录>
产品参考图：<可锁定外形、比例、颜色、材质、结构和Logo的清晰图片；卡券则填真实权益页>
风格参考：<风格参考图/视频；没有独立图片时写“以对标视频为风格源”>
复刻模式：<高保真视觉复刻 / 爆款机制迁移 / 商业混合复刻，三选一>
节拍密度：<跟随原片 / 标准密度 / 高密度反转>
制作范围：<素材包 / AI表交付 / 完整视频>
运动类型：<参考片主导 / 剧情表演 / 连续运动广告>
视觉世界硬约束：<必须保持的媒介、人物/IP方向、时代或画面质感；没有则写“未指定”>

目标：
- 视频源真实锁定身份并双ASR/固定0.5秒全片逐张看；静态源逐图SHA与观察，不伪造视频证据。
- 分析画面、对白、人物关系、情绪、运镜、黄金三秒、冲突和反转。
- 先声明本次复刻模式及推断理由，不能把三种模式混用。
- 为每个镜头建立“对标时间码→脚本→分镜文件→Seedance提示词”的唯一编号。
- 按所选模式执行保留项和替换项，不额外套用其他模式规则。
- 高保真模式跟随原片完整时长；其他模式按指定时长。按模型限制拆成若干1至15秒片段；高保真每段最多3个原片因果节拍，不得为凑少量片段删除表演或反转。
- 每张分镜为独立9:16画面，禁止九宫格；写AI表时人物、分镜、音频和商品素材合计不超过9个附件。
- pre-visual后先做完整场景母样与人物细节两张独立校准，真实传入style_only源图并六轴对照；通过后再统一人物与分镜。
- 每段输出一个可直接复制到本次锁定Seedance模型的完整提示词。
- 每段提示词逐一写明人物设定、分镜图片和音乐附件的真实文件名及作用。
- 竞争3至5套概念（连续运动广告10套），由独立编辑找划走点和反转证据；评分仅比较，桌读检查具体商业关联，不伪造商品删除后故事必断。
- 建立schema v5的`08_replica_contract.json`，记录机制DNA、候选方案、评分、淘汰理由、桌读结果，锁定用户原始模式/时长/制作范围，并验证所有原片Rxx节拍均映射到脚本Sxx、分镜文件、提示词Pxx和运动节拍。
- 创建`02_visual_lock.md`，用文件哈希锁定产品参考资产和六项不可变特征；建立唯一风格lock_id与完整可复用提示词，并逐段带入。
- 每个Pxx写完整运动链和handoff交接锚点；删除运镜后主体仍须有动作，复杂动作必须有起/中/终三态关键帧。
- 在合同中完成`narrative_qc.story_chain`：问题→人物选择→可见后果→回答开头；商品必须承担戏剧作用。补全`dialogue_requirements`、`prop_continuity_requirements`、`director_requirements`和二选一的`finale_policy`。
- 逐秒脚本使用可解析Markdown时间表；运行`analyze_script.py`自动计算可执行单元、说话轮次、最低口播秒数、语速、商品事实密度和无解释魔法，不允许人工自报覆盖。
- 原片音乐/音效参与反转时，按时间码截取并写明在视频中的使用区间。
- 有扇面、招牌或包装指定文字时，逐字生图并实际验图，禁止错字或镜像。
- 所有人只说中文普通话，生成画面不出现字幕、二维码和无关文字。
- 商品权益和限制必须以素材为准，不得夸大。
- 暂时不生成视频，不发布。
- `run_quality_gate.py --stage pre-generation`必须返回`allow_generation`；否则按`return_to_stage`退回对应层修改。
```

如需写入钉钉AI表，再追加：

```text
- 写入前读取目标子表、字段和记录；自动视频、公式和生成结果字段只读不写。
- 更新附件必须保留原有有效附件，只替换指定文件；写后回读提示词、附件和视频结果列。
- 不点击生成按钮。
```

如需生成成片，再追加：

```text
- 使用VidMuse完整制作时，先读取技能内`references/vidmuse_full_production.md`。实时检查登录、会员、积分、可用模型、生成参数和时间线/导出能力；模型或能力不可用时停止，不自动回退。
- 音乐必须在视频生成前锁定并分析真实节拍；未确认时只产出3个候选后暂停。
- 生成计划包含每个镜头的预计积分和至少一次复杂镜头重生预算；积分不足时在生成前停止。
- 每个镜头完整播放并检查连续帧，只修改一个主要变量后定向重生，连续两次失败停止报告。
- 禁止把产品图、人物图、故事板或动作关键帧放进时间线充当动态镜头；禁止Ken Burns、数字推拉/抖动等伪动态。
- 生成后逐条回读AI表：记录ID、Clip ID、结果视频文件名/链接、实际时长、分辨率和完成状态必须一一对应；下载所有结果后按Clip时间顺序合片，禁止按下载时间拼接。
- 每段实际时长与合同片段时长不一致超过0.5秒、片段缺失、顺序错误或人物/道具/因果链断裂，判定不合格并回到脚本或提示词重做；不得把“已生成”称为可发布成片。
- 建立`09_delivery_manifest.json`、`10_asr_manifest.json`和带真实Watch证据帧的`11_director_qc.json`；`run_quality_gate.py --stage pre-stitch`返回`allow_stitch`后才允许合片。
- 合片后对最终MP4本身重跑`prepare_reference.py`双模型ASR，建立带最终视频、ASR证据和事实图哈希的`13_final_manifest.json`。所有模式必须用`--final-manifest`运行`pre-publish`；真实听音人填写音频质检后，门禁返回`allow_publish`才可发布。
- 高保真最终成片额外运行`validate_render.py`并把结果传给发布前总门禁。
```

说明：“逐帧”是全片固定0.5秒逐张、场景关键帧、开头/转折加密复核，另查实际首末编码帧；不宣称看完全部24/30fps编码帧。

可选补充：目标人群、剧情方向、视频总时长、必须保留的卖点、不能出现的内容。

模式速选：

- 要镜头顺序、时长、机位、运镜和动作尽量像原片：高保真视觉复刻。
- 要换题材，只保留停留、误判、反转和传播机制：爆款机制迁移。
- 视频源要前三秒冲突后保持原视觉节拍：商业混合；静态插画商业混合则继承画法并原创全片时序。
